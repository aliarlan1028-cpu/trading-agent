## 1. 当前系统实际架构

- **后端**：Node/Express 单进程，唯一入口 `server/index.mjs`（2597 行：205 条路由 + 启动迁移 + 17 个任务处理器注册 + 实时 tick hook）。持久化 `store.mjs`（SQLite collections JSON blob + OMS/Outbox/审计链关系表）。
- **前端**：React/Vite 无路由库；桌面 `App` 手工 switch 7 页 + 侧栏 6 项；移动端 `MobileApp` 独立一套（抽屉导航 7 页）；面板由字符串 key（`openPanel("x")`）驱动 `ConfigPanel` switch。
- **Agent**：主 Agent = `agentChat.mjs`（TOOL_DEFS 20 工具 + skillTools + MCP 动态注入）；另存一套**自述 DEPRECATED** 的平行实现 `llmAgent.mjs + toolRouter.mjs`（仅 `/api/llm-agent/run` 可达）。
- **部署**：两条互不知晓的链路——主实例 `deploy/deploy.sh`（rsync→远端 build→验证→回滚）与租户 `provision-tenant.sh`；交汇点仅 `monitor-tenants.sh`。
- **iOS**：Capacitor 打包 dist，SPM 装 5 个插件。
