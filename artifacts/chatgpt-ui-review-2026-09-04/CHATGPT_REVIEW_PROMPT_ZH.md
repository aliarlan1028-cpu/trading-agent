# 给 ChatGPT 的界面检查提示词

请检查我上传的 `KORDYN-UI-Review-2026-09-04.zip`。这是一个 AI 交易产品的桌面端与 APP 全界面截图包。

请先完整阅读 `README.md`，然后按以下顺序检查：

1. `contact-sheets/03-auth-all.jpg`：公开首页、登录、2FA、注册流程。
2. `contact-sheets/01-desktop-all.jpg`：桌面端 01–45。
3. `contact-sheets/02-app-all.jpg`：APP 01–45；同编号与桌面端逐张比较。
4. `contact-sheets/04-desktop-overlays.jpg` 与 `05-app-overlays.jpg`：弹窗、抽屉、详情面板和危险操作确认。
5. 遇到问题时，必须再打开 `screenshots/` 内对应原尺寸 PNG，不要只看压缩后的总览拼图。

请重点检查：

- 信息架构、模块命名、导航层级和用户任务路径是否清楚。
- 同一编号的桌面端/APP 是否表达同一个任务；移动端的删减或合并是否合理。
- README 第 6 节列出的路由合并，是合理复用、误导性重复入口，还是实际缺页。
- 交易、风控、订单、复盘和设置中的主次操作、危险操作、状态提示是否符合金融产品的安全预期。
- 字号、对比度、密度、留白、按钮层级、可点击性、表格可读性、触控尺寸与底部导航是否合适。
- 是否缺少空状态、加载态、失败态、断网态、权限不足、确认态、成功反馈和恢复路径。
- 文案、数字格式、盈亏颜色、时间、币种、单位和数据绑定是否一致。
- 特别核对 APP 44、45 的空内容，以及 APP 复盘列表里多条记录显示相同盈亏数字的问题。

请不要根据文件名臆测截图外的功能，也不要把脱敏演示数据当作线上真实数据。截图使用稳定的已加载状态，未执行真实交易或其他服务端写操作。

请用中文给出以下交付：

1. **总体结论**：产品成熟度、最强点、最大风险，并给桌面端、APP、跨端一致性分别打 0–10 分。
2. **问题清单**：用表格列出 `优先级(P0–P3) / 截图编号 / 平台 / 证据 / 问题 / 用户影响 / 建议修复`。
3. **跨端差异**：逐项说明哪些是合理的响应式差异，哪些是缺失或语义不一致。
4. **路由与流程审查**：判断重复入口、合并页面和返回路径是否合理。
5. **缺失状态**：列出仍需要补充设计或补截图的状态。
6. **整改路线图**：给出最优先的 10 项修改，按依赖关系和收益排序；区分“必须修复”“应优化”“可探索”。
7. **可直接执行的设计建议**：对前 5 个问题给出具体到布局、文案、组件状态或交互的修改方案。

如果某个结论无法仅凭截图确认，请明确写“需要产品/代码验证”，不要当成已确认事实。
