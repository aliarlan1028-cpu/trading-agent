# 知识交易技能闭环

## 目标与边界

系统把用户实际上传的书籍、网页和笔记分成两类：

1. 顾问知识：可被 RAG 检索和引用，但不能直接驱动自主交易。
2. 知识交易技能：经过受限编译、历史样本外验证、纯前向模拟盘验证和人工批准后，才允许参与交易计划。

“只输入书名”产生的是模型合成综述，不是用户提供的原始证据。此类来源永久禁止编译为自主交易技能。

## 生命周期

```text
compiled
  ├─ historical_rejected
  └─ historical_validated
       └─ paper_validating
            ├─ paper_rejected
            └─ paper_validated
                 └─ live_probation（人工批准后的小额实盘试用）
                      └─ active（真实成绩达标转正）
                      ├─ degraded
                      ├─ superseded
                      └─ retired
```

- `compiled`：已映射到白名单策略模板，但不可执行。
- `historical_validated`：通过 40/30/30 时间顺序训练、验证、测试三窗检查。
- `paper_validating`：纯前向模拟中；历史预热样本不能毕业。
- `paper_validated`：模拟盘达到样本、期望、盈亏比和回撤门槛，等待独立审批。
- `live_probation`：历史与纯前向验证通过、人工审批且批准指纹一致后的小额实盘试用态。
- `active`：小额试用真实成绩达到门槛后转正，可被 Agent 选择。
- `degraded`：实盘归因表现触发保护阈值，立即失去执行资格，可重新研究和验证。
- `superseded`：同一来源的新版本已生成。
- `retired`：人工退役或来源被删除、重解析。

任何状态变化都会写入技能自身的 `lifecycle` 和系统审计日志。

## 受限编译

编译器不会运行由书籍或模型生成的代码。它只允许将自然语言方法映射到系统已有的白名单模板，例如：

- 唐奇安突破 / 跌破
- 均线趋势 / 死叉做空
- RSI 均值回归 / 超买回落
- MACD 动量
- 布林带反弹
- RSI 顶底背离

编译必须具备：

- 明确的 long 或 short 方向；
- 支持的周期：5m、15m、1h、4h、1d；
- 入场条件；
- 止损条件；
- 止盈或离场条件；
- 真实上传来源。

确认条件和失效条件也必须编译为确定性结构。当前支持成交量高于指定周期均量，以及高影响事件失效保护；无法编译的确认/失效条件会使技能进入 `compile_failed`，不会再只保存一段文字却按通用模板执行。入场描述中的突破周期、均线周期和 RSI 参数会固化进技能指纹。

`both` 方法会拆成独立的多头和空头技能版本。无法安全映射的内容保留为顾问知识并标记 `compile_failed`。

## 验证门槛

历史验证使用时间顺序切分，不随机打乱：

- 训练窗：前 40%；
- 验证窗：中间 30%；
- 测试窗：最后 30%；
- 验证与测试都必须为正期望；
- 合并样本外至少 8 笔；
- 验证、测试各至少 3 笔；
- 盈亏比不低于 1.05；
- 最大回撤不高于 20%。

历史验证的交易对和周期必须与技能范围一致。通配符技能只能用于实际逐一验证过的交易对。历史通过后必须创建从当前时刻开始的纯前向模拟盘。模拟盘只处理已闭合 K 线，并扣除双边手续费、滑点和持仓期间资金费率；默认至少 30 笔，期望 90% 下界大于 0、盈亏比不低于 1.1、最大回撤不高于 20%。带历史预热的会话不能获得毕业资格。

## Agent 调用与风控

Agent 只从 `active` 技能中按交易对、方向、周期和市场状态筛选，并用编译后的完整规则检查最近一根闭合 K 线。技能必须同时满足“当前触发”和“Agent 在 `knowledgeSkillIds` 中明确声明采用”才会绑定计划；未采用或未触发的技能只记录为候选评估，不能计入调用或收益归因。计划会固化：

- 技能 ID；
- 技能版本；
- 内容 SHA-256 指纹；
- 模板 ID；
- 来源与引用；
- 匹配分数。
- 触发信号的闭合 K 线时间。

风控检查和执行前复查都会重新确认技能仍为 `active`，验证版本和指纹一致，并重新计算当前信号、周期、事件失效条件和信号年龄。技能在计划生成后被降级、替代、退役或信号消失时，旧计划会被拒绝执行。
对于固定百分比止损和 R 倍数止盈，风控还会检查计划参数是否与编译技能一致；不能只挂技能名称、却使用另一套止损止盈参数。

## 归因与退役

已平仓成交会先按执行订单聚合部分平仓，再通过 `tradePlanId` 回溯到计划明确采用的技能。多个明确采用的技能共同参与时，收益按等权保存为独立归因记录，并标明归因方法，不篡改原始成交盈亏。

每个技能持续统计：

- 归因交易数；
- 胜率；
- 加权盈亏；
- 盈亏比；
- 连续亏损次数。

达到最小实盘归因样本后，如果盈亏比低于 0.8，或近期连续亏损达到 5 次，技能自动进入 `degraded` 并停止被 Agent 调用。人工可以随时退役；来源删除或重解析也会退役旧版本。

## API

- `GET /api/knowledge/skills`
- `POST /api/knowledge/methods/:id/compile`
- `POST /api/knowledge/skills/:id/validate`
- `POST /api/knowledge/skills/:id/paper`
- `POST /api/knowledge/skills/sync`
- `POST /api/knowledge/skills/:id/approve`
- `POST /api/knowledge/skills/:id/retire`

审批使用独立权限 `approve:knowledge_skill`，普通交易用户不能自行批准知识技能。
