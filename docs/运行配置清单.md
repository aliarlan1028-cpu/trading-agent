# AI Trading Agent 运行配置清单

## 本地启动

1. 复制 `.env.example` 为 `.env`。
2. 填入你自己的模型、交易所、链上、告警与 LangSmith 配置。
3. 启动服务：`npm run dev`。
4. 打开前端：`http://127.0.0.1:5173/`。

## 交付命令

- `npm run build`：构建前端。
- `npm run smoke`：覆盖主要后端工作流。
- `npm run healthcheck`：检查 API、就绪度和审计链。
- `npm run backup`：调用系统备份接口，输出备份文件路径。

## 实盘前必须由你确认

- 交易所 API Key 禁止提现权限。
- API Key 设置 IP 白名单。
- `LIVE_TRADING_ENABLED=true`、`I_UNDERSTAND_REAL_TRADING=true`、`REAL_ORDER_WRITE_ENABLED=true` 只能在你确认后开启。
- 先启用小额度灰度策略，默认建议 `MAX_LIVE_NOTIONAL_USDT=50` 或更低。
- 逐项验证下单、撤单、改单、平仓、移动止损、分批止盈。
- 验证 Binance/OKX 私有 WebSocket 与 REST 对账一致。
- 验证 Docker Skill 沙箱可用，且第三方 Skill 无直接交易权限。

## 已由代码实现的能力

- React 驾驶舱与全模块导航。
- Express API 与 SQLite 持久化。
- Mandate 授权、RiskEngine、灰度实盘、小额度人工确认。
- Binance/OKX 行情、只读同步、私有 WebSocket 准备与交易写网关。
- LLM Agent、ReAct Tool Calling、LangSmith 记录入口。
- PDF/DOCX/网页/GitHub 知识导入、切片、RAG、专家图谱。
- RSS/HTML/链上事件源。
- Skill 拉取、扫描、安装、禁用、回滚、Docker 沙箱。
- 加密金库、不可变审计链、告警、安全演练、备份与健康检查。
