# 专业风险硬闸门

## 执行顺序

新开仓必须依次通过：授权与计划风控、专业风险闸、专业仓位上限、SRTL 结构审核、交易写网关。撤单、平仓、移动止损和 reduce-only 订单不受新开仓闸门阻断。

## 硬阻断条件

- 行情超过 `SLO_MARKET_FRESHNESS_MS`；
- 私有 WebSocket 已启动但断开；
- 存在 `UNKNOWN` 执行订单；
- 已配置私有账户但对账异常或超过 `SLO_RECONCILIATION_FRESHNESS_MS`；
- 审计链被标记异常；
- 组合波动预算达到或超过 100%；
- 缺少可验证盘口深度，或预计冲击超过 Mandate 的 `maxImpactBps`；
- 任一可计算持仓的强平距离低于 `minLiquidationDistancePct`；
- 同向相关仓位超过 `maxCorrelatedPositions`；
- 系统已经处于只减仓或熔断状态。

## 仓位压缩

- 盘口容量把订单名义额压到允许冲击成本以内；
- 组合波动预算使用率超过 80% 后逐步压缩；
- 已有高相关暴露时追加 50% 压缩；
- 最终仍受灰度名义额、组合波动上限和单笔止损风险上限约束。

## 自动降级

运行链路异常时系统关闭自主推进、开启 `reduceOnlyMode`、写入风险事件、审计和 Trace。系统恢复后不会自动解除只减仓，必须由有权限的用户确认故障已处理后手动解除。
