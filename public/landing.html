权限与风控 · GUARDRAILS

都在清晰的规则中进行。

交易权限、密钥隔离与紧急停止被落实在系统中，让 Agent 可以自主行动，也始终保持在你设定的范围内。

紧急停止 · EMERGENCY CONTROL READY
DENY
禁止提现权限

Trade 权限仅授权后启用,Withdraw 永不开放。

ISOLATE
API Secret 隔离

不进入模型上下文、前端与普通日志。

BLOCK
无止损即拒绝

无止损、超杠杆、超单笔风险的计划直接驳回。

FREEZE
高影响事件禁新仓

对账异常或高风险事件时仅允许降风险动作。

SANDBOX
第三方 Skill 不可直连

扫描、沙箱、权限声明后才能启用,不得直接下单。

AUDIT
全程 append-only 审计

交易、授权、风控与密钥变更不可被删除。
