# Trading Agent — 策略与架构最终方案与需求文档

- 版本：v1.0
- 日期：2026-08-03
- 状态：待用户批准（本文件是决策依据 + 执行需求，不是已实施记录）
- 适用范围：交易信号/策略层、决策架构、产品定位、上线验证纪律。**不涉及**已稳定的下单执行、风控硬闸、账户对账、部署链路（这些保持现状）。

---

## 0. 结论摘要（TL;DR）

一句话：**停止把系统当"自主 alpha 引擎"来建（数据证明方向 TA 无成本调整后的 edge），把核心产品诚实重定位为"纪律型交易副驾"；结构性 alpha 作为受硬闸约束的独立研究轨道，验证通过才上线；同时清理"策略散落三家互相矛盾"的技术债，并把"上线前成本调整+跨 regime+样本外验证"固化为永久硬闸。**

四条并行工作流：
- **WS-0（政策）**：上线前验证硬闸 —— 任何策略进实盘前必须过"成本调整 + 跨 regime + 样本外 + paper-forward"。这是本轮最重要的产物。
- **WS-1（止血，低风险，先做）**：策略真理源合并 —— 消灭 scanner/doctrine/硬编码三家矛盾。
- **WS-2（核心方向）**：产品重定位为纪律副驾 —— 围绕系统真正强的能力（风控、消息面综合、复盘、执行纪律）设计与表述，不承诺收益。
- **WS-3（受闸研究，可选上升）**：结构性 alpha 研究轨道（资金费/基差/清算级联），先便宜 spike，过 WS-0 硬闸才谈上线。
- **WS-4（条件触发，不无条件做）**：skill 架构迁移 —— **仅当 WS-3 找到经验证的 edge**、有值得"做成可维护 skill"的东西时才启动。

---

## 1. 背景与证据

### 1.1 本轮调查脉络（事实链）
1. 用户反馈"信号滞后、追涨杀跌、一碰就止损"。
2. 定位根因：`opportunityScanner` 打分把"贴 24h 上沿/已大涨"评为最佳做多、"贴下沿/已大跌"评为最佳做空——**系统在主动挑末端追单**，与自身纪律 S1「顺势回调,不摸顶」/S2「不追突破」矛盾；`sync_market` 又算了相反的"追末端慎多"警告却没被使用。→ 已修（反追涨打分 + 真实 ATR 止损 + 回调入场，见 commit `823b0c4`）。
3. 更正一处过度断言：旧止损 `48h区间×0.25 ≈ 2.75×(1h ATR)`，是**合理**倍数，不是"4× 过紧"；"一碰就止损"的主因是**追末端进场**，不是止损宽度。
4. 追问"是否把很多策略焊进了系统"→ 发现策略散落在**三个互相矛盾的家**（硬编码启发式 / LLM 散文 doctrine / skill 流水线）。
5. 讨论"纯 skill 直接调用 vs 现状"→ 我给出三层架构方案 → 用户要求自我批判 → 承认方案"终态对、作为下一步本末倒置"（在没确认 edge 前先建验证工厂）。
6. 决定：先做便宜、不碰钱路的 **edge 寻优 spike**，用结果决定"迁移 vs 换策略类"。

### 1.2 核心证据：edge 寻优 spike（决定性）

方法（严格）：真实 OKX 250 天 1h K 线 × 8 币；6 个策略族 × 参数共 12 个配置；计入成本（taker 0.05%×2 + 滑点 0.03%×2 + 资金费 0.00125%/h，共约 0.16% 往返 + 时长项）；**非重叠成交**（同配置同币一次一仓）；指标严格只用 ≤i 数据（无未来函数）；按 500 根分 block 看跨时段一致性；按 ADX 分 trend/range 看跨 regime。

结果：**12 个配置无一净期望为正。**

| 策略配置 | 毛期望R | 净期望R | 正block比 | 趋势regime净R | 震荡regime净R |
|---|---|---|---|---|---|
| TF-breakout20 · 2R（最好） | +0.084 | **−0.026** | 5/12 | −0.025 | +0.045 |
| MR-rsi(25/75) · 2R | +0.031 | −0.068 | 5/12 | −0.043 | −0.009 |
| TF-pullback · 1.5R（已上线的入场逻辑） | −0.005 | −0.114 | 4/12 | −0.142 | +0.097 |
| 其余 9 个 | ≤0 | −0.11 ~ −0.15 | ≤5/12 | 负 | 多数负 |

关键读数：
- **毛期望本就近零**（方向 TA 在流动币上 ≈ 有效市场），**成本（每笔 ~0.06–0.11R）把微弱毛利翻成净负**。
- **均值回归是假象**：前期"无成本 + 50 天震荡窗口"看到的 +0.2R，放到"计成本 + 250 天多 regime"后转负（−0.07 ~ −0.14）。spike 正是为抓这个假象而设计。
- "震荡里 MR 略正、趋势里赔"确实存在但**随 regime 翻号、净额不足翻正** → 盲目逆势会在趋势里被打爆。

### 1.3 三条硬结论
- **H1**：朴素方向 TA（动量/突破/RSI-MR/区间-MR/趋势回调）+ 固定 ATR 止损 + taker 成交，在本样本上**无成本调整后的稳健 edge**。
- **H2**：策略逻辑散落三家、互相矛盾，是可复现 bug 的结构性来源（追涨 bug 即此）。
- **H3**：系统真正强的是**纪律与风控**（消息面综合、风控硬闸、复盘闭环、执行安全、防用户情绪化），这些价值**不依赖是否拥有 alpha**。

### 1.4 证据的边界（不过度外推）
H1 **只**证明"朴素方向 TA + 固定止损 + taker"在此样本净负。**未**证明：其他策略类不行（结构性未测）；maker/限价成交不行（能砍约一半手续费）；其他周期/资产不行；配合真实催化剂的人机择时不行。→ 这是 WS-3 存在的理由。

## 2. 最终方案（方向决策）

### 2.1 核心定位：纪律型交易副驾（不赌 alpha）
把产品主线定位从"自主 alpha 引擎"改为**"有纪律的交易副驾"**：帮用户做多源信息综合、风控边界执行、计划审查、复盘沉淀、防止追涨杀跌与情绪化——**价值不依赖系统自己能否跑赢市场**。这是诚实且系统真能做好的定位。

### 2.2 结构性 alpha：受闸的独立研究轨道（可选上升）
alpha 不作为核心承诺，作为**受 WS-0 硬闸约束的研究实验**：优先测不靠预测的结构性优势（资金费收割/基差、清算级联反打、跨所/跨期价差），先便宜 spike，过闸才 paper-forward → gray。找到就是上升红利，找不到不影响 2.1 的产品价值。

### 2.3 永久硬闸：上线前验证纪律（本轮 meta 产物）
把本轮血的教训固化为不可绕过的政策（WS-0）：**任何策略进实盘前，必须通过成本调整 + 跨 regime + 样本外 + paper-forward 验证。** 这条从制度上防止"把没验证的策略/未过拟合检验的信号推上真钱"。

### 2.4 架构：三层分工 + 止血合并
| 关注点 | 唯一的家 | 理由 |
|---|---|---|
| 优势（入场/止损/目标/regime 打法） | 确定性 skill（数据） | 只有它能回测+陪跑+证伪；改策略=改数据不改代码 |
| 安全（名义额/白名单/杠杆/日亏/相关性） | 代码 riskEngine | 不变量，绝不做成可关的 skill |
| regime/性格分类 | tokenProfile（Hurst/方差比） | 确定性可测，输出用于选 skill |
| 选择 + 否决 + 讲解 | LLM | 读消息面/新事件，回测编码不了；**只能收紧风险，不能凭空编入场/止损** |

止血（WS-1）：把散落数字按上表归位，`deterministicDecision`/`opportunityScanner` 降级为纯兜底，消灭三家矛盾。**架构全面 skill 化（WS-4）不无条件做**——只有 WS-3 产出经验证 edge 时才值得。

## 3. 需求文档（工作流）

> 每个 WS 给：目标 / 范围 / 验收标准 / 非目标 / 风险与依赖。

### WS-0：上线前验证硬闸（政策 + 工具）
- **目标**：制度化"无验证不上线"，任何策略/信号进 gray 前必须过闸。
- **范围**：
  1. 把本轮 spike 方法固化为可复用的**回测验证器**（多币 × ≥6 月历史 × 计成本 × 非重叠 × 分 block × 分 regime）。
  2. 定义**晋级判据**（见验收）。
  3. 与既有 paper-forward 转正条件对接（`MIN_FORWARD_TRADES=30` + `expectancyLower90R>0` + `profitFactor≥1.1` + `maxDrawdown≤20%`）。
- **验收标准（晋级到 paper-forward 的门槛）**：一个策略配置，在 ≥6 个月历史 × ≥8 币上，必须同时满足：
  - 成本调整（taker+滑点+资金费）**净期望 R > 0**；
  - 净期望 R 在 **≥60% 的非重叠时间 block** 为正；
  - 在 ADX-趋势 与 ADX-震荡 **两个 regime 桶都不为负**；
  - 最差 block 净 R 不低于 **−0.15**（无灾难性时段）。
  - 过闸后进 paper-forward；paper 达既有转正条件才谈 gray。
- **非目标**：不追求把回测做成完美研究平台；够用、可复现、诚实即可。
- **风险**：单交易所/单一 250 天样本仍可能偏；缓解 = 后续持续扩样本 + 强制 paper-forward 前向确认。

### WS-1：止血 —— 策略真理源合并（低风险，先做）
- **目标**：一个关注点一个家，消灭 scanner/doctrine/硬编码三家矛盾（追涨 bug 之源）。
- **范围**：
  - 产出**策略数字边界表**：把 `deterministicDecision`（权重/阈值/stop）、`opportunityScanner`（打分/回调理想位）、`tokenProfile`（Hurst/VR 阈值）、`riskThresholds` 每个数字打标"优势→skill / 安全→代码 / 分类→分类器"。
  - 把已焊进 scanner 的反追涨/ATR 逻辑**收敛为可参数化的一处**，`deterministicDecision`/`scanner` 明确降级为"无 skill/无 LLM 时兜底"。
  - 消除 `sync_market`（警告追末端）与 `scanner`（奖励追末端，已修）之类的口径矛盾，保证同一概念只有一处定义。
- **验收标准**：无重复/矛盾的策略数字；边界表评审通过；`npm test` 全绿 + 新增回归测试锁定"不再出现追末端优先"。
- **非目标**：此阶段**不**改变实盘行为的净效果（纯重构 + 去矛盾）；不做 skill 化迁移。
- **风险**：重构触及决策路径 → 用单测 + 不改净行为为纪律；小步提交。

### WS-2：产品重定位 —— 纪律副驾（核心方向）
- **目标**：产品表述与功能围绕"纪律副驾"，去除"自主 alpha/稳赚"暗示，突出系统真强项。
- **范围**：
  - **表述审计**：UI/落地页/文案中任何"自动盈利/跑赢/alpha"类暗示，改为诚实能力表述（信息综合、风控执行、复盘、纪律）。
  - **强化真价值功能**：消息面综合与催化剂归因、风控硬闸可视化、计划审查清单、复盘闭环、追涨杀跌/情绪化拦截提示、执行安全。
  - 明确对用户的价值主张：**"帮你更有纪律地交易、并守住风控"，而非"替你赚钱"。**
- **验收标准**：全站无未经验证的收益承诺；核心副驾能力在信息架构中清晰可达；用户能一眼看懂"这系统帮我做什么、不保证什么"。
- **非目标**：不删除交易执行能力（授权用户仍可用），只是不把"自主盈利"作为卖点。
- **风险**：与商业预期的落差 → 用诚实换可持续信任（本项目一贯"不造假数据"的延续）。

### WS-3：结构性 alpha 研究轨道（受闸，可选上升）
- **目标**：便宜地检验非预测型结构性优势是否存在，过闸才推进。
- **范围（先做第一个）**：
  - **资金费收割/基差** spike：用 OKX 公开资金费历史，检验 delta 中性收资金费扣除再平衡/成交成本后的净期望；
  - 备选：清算级联反打（极端插针后均值回归，有明确触发）；跨所/跨期价差。
- **验收标准**：每个候选必须过 **WS-0 硬闸** 才能进 paper-forward；不过闸则如实归档"未发现 edge"，不上线。
- **非目标**：不承诺一定找到 edge；不绕过硬闸。
- **风险**：结构性策略有执行/对手方/资金费翻转风险 → 纳入 WS-0 成本模型 + 小额 gray 验证。

### WS-4：skill 架构迁移（条件触发）
- **目标**：把经验证的 edge 做成可维护、可版本化、可回测的 skill，作为实盘主干。
- **触发条件**：**当且仅当 WS-3 产出至少一条过 WS-0 硬闸的策略。** 否则不启动（不给不存在的优势抛光）。
- **范围（触发后）**：扩展 skill spec 表达力 → 把该 edge 落成 skill → 巡检循环改为"LLM 选已验证 skill、skill 出确定性入场/止损、风控闸校验、人工/gray 批准"；`deterministicDecision`/`scanner` 保持纯兜底。
- **验收标准**：策略改动 = 改数据 + 回测 + paper-forward + 转正，不发代码逻辑；风控闸仍为代码硬闸；回滚 = 切版本。
- **风险**：触及钱路 → 分阶段、每阶段 paper-forward 验证、灰度小额先行。

## 4. 路线图与闸门

```
现在 ──► WS-1 止血(边界表+去矛盾, 低风险)         ┐
        WS-0 验证器工具化(固化 spike 为可复用闸)   ├─ 可并行, 不碰钱路
        WS-2 表述审计起步(去 alpha 暗示)           ┘
          │
          ▼
        WS-3 结构性 spike(先资金费收割)
          │
     ┌────┴─────┐
   过 WS-0 闸    未过闸
     │            │
     ▼            ▼
   WS-4 迁移    归档"无 edge", 深化 WS-2 副驾定位
  (skill 化,    (不做 WS-4, 不上线该策略)
   paper→gray)
```

闸门原则：**每一步都有明确的"过/不过"判据；不过就不往下走，如实归档，绝不带着未验证的东西上真钱。**

---

## 5. 风险与限制（诚实边界）
1. **样本限制**：250 天/单交易所/存活币种，仍可能有 regime 偏与幸存者偏差 → 靠持续扩样本 + 强制 paper-forward 前向确认缓解。
2. **成本敏感**：edge 门槛是每笔 ~0.1R 成本；maker 成交、降频高确信可减负，但不是万能。
3. **非平稳**：任何回测过的策略都可能因 regime 变化失效 → 靠 paper-forward + 小额 gray + 持续绩效打分与自动降级（注意：绩效方差大，统计确认慢，故务必小额）。
4. **skill 化 ≠ 盈利**：架构让 edge 可发现/可验证/可淘汰，不制造 edge。
5. **LLM 不可验证性未消除，只缩小**：改为"选已验证 skill + 只能收紧风险"，方向/择时仍含不可回测判断。

## 6. 附录：术语
- **净期望 R**：每笔交易以"止损距离=1R"归一后、**扣除成本**的平均盈亏。>0 才有正期望。
- **regime**：市场状态；本文用 ADX≥25 记趋势、<20 记震荡。
- **walk-forward / 分 block**：把历史切成连续时段分别评估，看 edge 是否跨时段一致（防单窗口过拟合）。
- **paper-forward**：真实行情、不用真钱的前向模拟车道；既有转正条件见 WS-0。
- **gray（灰度）**：小额真钱、限币种、多重安全闸的实盘验证阶段。
